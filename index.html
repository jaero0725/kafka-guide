Apache Kafka 4.3.x 기준 · KRaft-first

Kafka Guide

Apache Kafka를 실무에서 쓰고 CCDAK · CCAAK에 합격하기 위한 한국어 가이드입니다. 모든 설명은 Kafka 4.3 기준이며, ZooKeeper는 4.0에서 제거되었으므로 KRaft를 유일한 모드로 서술합니다. 3.x와 동작이 다른 지점은 버전 노트로 병기합니다.

이 페이지는 Wave 0 기반 구축 단계의 스텁입니다. 진도 대시보드(전체 진도 %, 도메인별 숙련도, 다음 학습 추천)는 Wave 4에서 완성됩니다. 아래 목록에서 아직 만들어지지 않은 페이지는 사이드바에 회색으로 표시됩니다.

여기서 시작하세요

  • 1. 진단 테스트 (30문항) 6개 도메인 취약점을 먼저 파악하면 학습 순서가 자동으로 정해집니다. 무엇부터 볼지 모르겠다면 여기부터. CCDAK 최우선

  • 3. 문제 풀이 허브 학습·시험·도메인 연습·오답 노트·약점 집중. 단일 선택·복수 선택·연결형·순서 배열 네 유형. 문제은행

항목기준
Kafka 버전4.3.x. 3.6~3.9와 다른 부분은 버전 노트로 병기하고, 2.x는 레거시 부록에서 다룹니다.
메타데이터KRaft 전용. ZooKeeper는 4.0에서 제거되었으므로 역사적 맥락에서만 언급합니다.
사실 확인설정명·기본값·CLI 옵션은 Apache Kafka 공식 문서와 소스에서 확인한 값만 씁니다.
문제 출처전 문항 자체 창작. 시험 덤프는 참조하지 않습니다.
외부 의존성CDN·웹폰트·프레임워크 0건. 오프라인에서도 열립니다.
진도 저장브라우저 localStorage 만 사용합니다. 서버로 전송되지 않습니다.
