플래시카드

CCDAK에서 설정 기본값과 예외 클래스 이름은 이해로 채울 수 없습니다. 반복 노출만이 방법입니다. 이 페이지는 간격 반복(spaced repetition)으로 "알았음" 3회 연속이면 졸업시키고, 모르는 카드만 계속 되돌려 줍니다. 하루 10분씩 매일 돌리는 것이 시험 전날 두 시간보다 효과적입니다.

사용법 요약

  • 아래 덱 선택에서 학습할 덱을 고릅니다. "전체"를 고르면 모든 CCDAK 덱이 섞입니다.
  • 카드를 뒤집기 전에 답을 소리 내어 말해 보세요. 뒤집고 나서 "알았다"고 느끼는 것은 착각입니다.
  • 애매하면 "몰랐음"을 누르세요. 연속 기록이 초기화되고 다시 나옵니다.
  • 진도는 브라우저에 저장되므로 다음에 열면 이어서 학습합니다.

조작 안내

키보드만으로 완주할 수 있습니다
키동작
Space 또는 Enter카드 뒤집기
1몰랐음 — 연속 기록이 초기화되고 다음 카드로
2알았음 — 연속 기록 +1, 3회 연속이면 졸업
→ 또는 N기록하지 않고 다음 카드
←이전 카드

아직 뒤집지 않은 상태에서 1이나 2를 누르면 먼저 카드가 뒤집힙니다. 답을 보지 않고 기록되는 일은 없습니다.

진행 상황이 표시되는 곳

세 곳에서 진도를 확인할 수 있습니다
위치표시되는 것
카드 아래 연속 정답 표시 점 3개로 현재 연속 기록. 3개가 모두 차면 졸업 표시가 붙습니다
카드 아래 이번 세션 이번에 앉아서 푼 "알았음 / 몰랐음" 개수
덱을 한 바퀴 돈 뒤 완주 화면 세션 정답률과 "이 덱에서 졸업한 카드: N / 전체". 여기서 몰랐던 카드만 다시 돌릴 수 있습니다
  • 학습 중 = 졸업하지 않은 카드입니다. 툴바의 "졸업 카드 제외"를 켜면 이것만 남습니다.
  • 졸업 = "알았음" 3회 연속을 달성한 카드입니다. "몰랐음"을 누르면 졸업이 취소됩니다.
  • 진도는 브라우저 로컬 저장소에 남습니다. 다른 기기·다른 브라우저와는 공유되지 않습니다.
  1. 1주차 — "설정 기본값" 덱만 매일 1회. 이 덱이 가장 배점 효율이 높습니다.
  2. 2~3주차 — 진단 테스트에서 약했던 도메인 덱을 추가합니다.
  3. 4주차 — "졸업 카드 제외"를 켜고 남은 카드만 집중적으로 돌립니다.
  4. D-1 — 졸업 카드 제외를 끄고 "설정 기본값" 덱을 전체 1회 훑습니다.

카드 학습

아래 툴바의 덱 선택 상자에서 학습할 덱을 고르세요. 셔플은 순서를 다시 섞고, 졸업 카드 제외는 이미 외운 카드를 숨깁니다.

"플래시카드 덱이 아직 없습니다"라고 표시되면 덱 데이터가 아직 생성되지 않은 상태입니다. 페이지는 정상이며, 데이터가 추가되면 이 자리에 자동으로 나타납니다.

"file:// 로 열면 JSON 로드가 차단됩니다"라고 표시되면 파일을 직접 열어서 생긴 문제입니다. 로컬에서 확인할 때는 프로젝트 루트에서 python3 -m http.server를 실행한 뒤 http://localhost:8000/ccdak/flashcards.html로 접속하세요.

암기 요령

소속을 값과 함께 외우세요

시험에서 가장 흔한 함정은 설정의 소속을 바꿔 놓는 것입니다 (함정 사전 패턴 2). 그러므로 max.request.size = 1048576이 아니라 max.request.size = 프로듀서 · 1048576으로 한 묶음으로 외우세요. 같은 이유로 message.max.bytes는 브로커 · 1048588, max.message.bytes는 토픽 · 1048588로 구분해야 합니다.

비슷한 것끼리 묶어서 외우세요

  • 타임아웃 4종 — 3000 / 45000 / 300000 / 500 (heartbeat / session / poll interval / poll records)
  • 크기 5+1개 — 1048576(프로듀서) / 1048588(브로커·토픽) / 1048576(컨슈머 파티션당) / 52428800(컨슈머 전체) / 1048576(팔로워)
  • 시간 예산 3종 — 30000(요청) / 120000(전달) / 60000(블로킹)
  • 기본이 0인 것 — errors.retry.timeout · num.standby.replicas · max.task.idle.ms · min.compaction.lag.ms
  • 기본이 1인 것 — num.partitions · default.replication.factor · min.insync.replicas · num.stream.threads · fetch.min.bytes · num.replica.fetchers

4.x에서 바뀐 것은 따로 외우세요

linger.ms 0→5, acks 1→all, enable.idempotence false→true, session.timeout.ms 10000→45000. 그리고 바뀌지 않은 것 하나 — group.protocol은 여전히 classic입니다. 시중 자료가 가장 많이 틀리는 지점이므로 이 다섯 개는 별도로 반복하세요.
