## 2. 홈 (index.html) — 이 Wave의 핵심 산출물

랜딩이 아니라 **학습 허브**로 만듭니다. 구성:

### (a) 히어로
- 한 줄 정체성: "Apache Kafka 4.3 기준, KRaft 시대의 실무·자격증 통합 가이드"
- 차별점 3개를 짧게: ① Kafka 4.x/KRaft 기준 ② 실제 장애 케이스 10건
  ③ 620문항 인터랙티브 문제은행
- 검색창 (/ 단축키 안내)

### (b) 진도 대시보드 (localStorage 기반)
- 전체 진도율 (읽은 페이지 / 전체 페이지)
- 섹션별 진도 바
- 퀴즈 숙련도: 시험별·도메인별 정답률 (인라인 SVG 바차트, 차트 라이브러리 금지)
- **다음에 학습할 것 추천**: 안 읽은 페이지 중 학습 순서상 가장 앞선 것,
  정답률이 가장 낮은 도메인의 챕터
- 최근 모의고사 이력 (점수·날짜)
- 진도 초기화 버튼 (확인 다이얼로그)
- **진도 데이터가 없는 첫 방문자**에게는 대시보드 대신 "여기서 시작하세요" 안내

### (c) 학습 경로 — CCDAK를 최상단에

이 사이트의 1순위 목표는 CCDAK 합격입니다. **CCDAK 경로를 가장 눈에 띄게** 배치하세요.

| 경로 | 대상 | 순서 |
|---|---|---|
| **★ CCDAK 합격 (기본 경로)** | 개발자 | **quiz/diagnostic → 진단 결과 기반 학습 순서 → 도메인 연습 → 모의고사 4세트 → traps/cram** |
| Kafka 처음 | 입문자 | ch01 → ch02 → ex01 → ch04 → ch05 → ex02 → … → CCDAK 경로 |
| 장애 대응 중 | 급한 사람 | cheatsheet/troubleshooting → cases |
| CCAAK 준비 | 운영자 | ccaak/index → 4주 플랜 |

**진단 테스트를 사이트의 기본 진입점으로 만드세요.** 히어로에서 가장 큰 CTA가
"30문항으로 내 약점 진단하기"가 되는 것이 합격률에 가장 도움이 됩니다.

### (b-2) ★ CCDAK 대시보드 (진도 대시보드 내 별도 블록)
